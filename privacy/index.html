Guardian Tab 隐私权政策

Chrome 扩展 · 最后更新：2025年3月

本隐私权政策说明了 Guardian Tab Chrome 扩展（以下简称「本扩展」）如何收集、使用和保护您的信息。使用本扩展即表示您同意本政策。

一、我们收集的数据

本扩展不收集、不上传任何个人数据。所有用户配置（包括自定义导航、代币列表、壁纸设置、主题偏好等）均仅保存在您设备本地的浏览器存储中，不会传输至任何外部服务器。

二、权限使用说明

为提供完整功能，本扩展需要以下权限。我们承诺仅将权限用于所述用途：

权限 用途说明
storage 在本地保存您的自定义导航列表、代币配置、壁纸设置和主题偏好，以便在新标签页中恢复您的个人配置。
webNavigation 监听页面导航事件，判断您访问的网址是否在您设置的导航白名单中，以实现安全导航保护功能。
host_permissions
（<all_urls>）		 1）向 Binance、Bybit 等交易所 API 发起请求以获取加密货币行情数据；2）在安全导航保护功能中解析您访问的 URL，判断是否属于白名单域名；3）可选的 Google Safe Browsing 威胁检测（仅在您主动开启并填写 API Key 后生效）。
content_scripts 在网页中扫描外链，识别与白名单域名相似的钓鱼链接或含敏感诱导词的链接并提示。此扫描完全在本地完成，不发送任何数据。

三、数据存储与安全

  • 所有数据均存储在 Chrome 的本地存储（chrome.storage.local）中，仅限您的浏览器访问。
  • 临时放行记录与威胁检测缓存仅保存在内存级存储（chrome.storage.session）中，浏览器重启后自动清除。
  • 我们不会将您的数据分享给任何第三方。
  • 卸载本扩展后，相关本地数据将随扩展一并移除。

四、第三方服务

本扩展会向以下第三方 API 请求公开市场数据（仅限价格等公开信息，不涉及个人数据）：

  • Binance API - 加密货币行情
  • Bybit API - 加密货币行情

这些请求由您的浏览器直接发起，我们不会经手或存储这些数据。

可选的 Google Safe Browsing 服务：如果您在设置中主动开启「Google Safe Browsing 实时检测」并填写自己的 API Key，扩展会将您访问的域名发送至 Google Safe Browsing API 进行恶意网站检测（检测结果本地缓存 30 分钟）。该功能默认关闭，未开启时不会向 Google 发送任何数据。

五、政策变更

我们可能会不时更新本隐私权政策。重大变更将在扩展更新说明或本页面中公布。继续使用本扩展即表示您接受更新后的政策。
