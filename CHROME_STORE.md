# Chrome 商店提交说明

本文档包含 Guardian Tab 扩展提交至 Chrome 网上应用店时所需的隐私权相关说明。

---

## 一、单一用途（Single Purpose）

**Guardian Tab 的单一用途：**

> 提供自定义新标签页，整合加密货币行情、自定义导航与安全导航保护，帮助用户集中查看市场信息、快速访问常用网站，并拦截未在白名单中的网站与疑似钓鱼链接。

---

## 二、需请求权限的理由（Permission Justification）

### 安装时请求的权限

| 权限                                 | 用途说明                                                                                                                                                                                           |
| ------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **storage**                          | 在本地保存用户的自定义导航列表、代币配置、壁纸设置、主题偏好与安全设置，以便在新标签页中恢复个人配置。                                                                                             |
| **webNavigation**                    | 监听页面导航事件，判断用户访问的网址是否在用户设置的导航白名单中，以实现安全导航保护功能。                                                                                                         |
| **host_permissions: "\<all_urls\>"** | 1）向 Binance、Bybit 等交易所 API 发起请求以获取加密货币行情数据；2）在安全导航保护功能中解析用户访问的 URL，判断是否属于白名单域名；3）在网页中扫描外链以识别钓鱼链接（仅本地比对，不发送数据）。 |

### 内容脚本（content_scripts）

| 项目         | 说明                                                                                                                                                     |
| ------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **匹配范围** | `http://*/*`、`https://*/*`（复用已有的 `\<all_urls\>` 主机权限，不额外增加权限警告）                                                                    |
| **用途**     | 扫描页面中的外链，识别与用户白名单域名高度相似的钓鱼域名，或链接文字含敏感诱导词（登录、钱包、验证、领奖等）的可疑链接，并在页面中提示、点击时二次确认。 |
| **数据处理** | 全部在用户本地完成，不与任何服务器通信，不采集、不上传页面内容。                                                                                         |

### 可选权限（按需申请，非安装时必须）

| 权限                                                                   | 用途说明                                                                                                                                                                                       |
| ---------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **optional_host_permissions: `https://safebrowsing.googleapis.com/*`** | 仅当用户在设置中主动开启「Google Safe Browsing 实时检测」并填写自己的 API Key 时才申请。用于把用户访问的域名发送至 Google Safe Browsing API 做恶意网站检测。默认关闭；关闭功能时会释放该权限。 |

## 三、版本更新说明（What's new，可直接粘贴到商店后台）

**1.1.0**

> 本次更新聚焦安全能力升级与操作提速：
> • 新增访问拦截页：被拦截时说明原因，可选择返回、加入白名单并访问或仍然访问
> • 新增钓鱼链接扫描：自动识别与白名单域名相似的钓鱼域名（如 gooogle.com、googlelogin.com）及含诱导词的可疑链接，并在点击时二次确认
> • 修复 HTTP 重定向可绕过导航白名单、以及导航链接协议未校验的安全问题
> • 新增可选的 Google Safe Browsing 实时威胁检测（默认关闭，可在设置中开启）
> • 新增首页快捷添加：市场与导航网格内直接添加，回车即完成，图标自动生成
> • 卡片支持悬停编辑/删除、双击编辑，编辑不再跳转设置页
> • 优化公共后缀域名判断（co.uk、com.cn 等），减少白名单误判

## 四、隐私权政策链接

部署隐私权政策页面至 Vercel 后，将生成的 URL 填入 Chrome 商店的「隐私权政策」字段。

例如：`https://guardian-tab-privacy.vercel.app`

> 注意：1.1.0 更新了隐私权政策内容（新增链接扫描与可选 Safe Browsing 的数据流说明），发布前请重新部署 `privacy/` 目录。
