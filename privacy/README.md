# Guardian Tab 隐私权政策

本目录包含 Guardian Tab Chrome 扩展的隐私权政策页面，可单独部署至 Vercel。

## 部署到 Vercel

### 方式一：从项目根目录部署（推荐）

1. 在 [Vercel](https://vercel.com) 导入 `guardian-tab` 仓库
2. 在项目设置中，将 **Root Directory** 设置为 `privacy`
3. 部署

### 方式二：使用 Vercel CLI

```bash
cd privacy
vercel
```

部署完成后，将生成的 URL（如 `https://xxx.vercel.app`）填入 Chrome 商店的隐私权政策链接。
